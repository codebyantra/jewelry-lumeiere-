# 💎 Lumière — Luxury Jewelry E-Commerce

A premium luxury jewelry e-commerce frontend crafted with **React 19**, featuring cinematic scroll animations, immersive UI interactions, and an elegant dark theme inspired by high-end jewelry brands.

## ✨ Features

- 💎 Cinematic GSAP + ScrollTrigger Hero Animation
- 🎬 Smooth scrolling with Lenis
- ⚡ React + Vite
- 🎨 Elegant dark luxury UI
- 📱 Fully responsive design
- 🛍️ Product listing & category showcase
- ❤️ Wishlist & Shopping Cart
- ⭐ Best Sellers & Testimonials Slider
- 🔍 Product Details Page
- ✨ Premium hover animations & micro-interactions
- ⚙️ External CSS (No Tailwind, No Bootstrap)

---

## 🛠️ Tech Stack

- React
- JavaScript (JSX)
- React Router DOM
- GSAP + ScrollTrigger
- Framer Motion
- Lenis
- Swiper.js
- React Icons
- Vite
